Background

One fundamental discipline within computer science is called 'algorithmic analysis' - it is the study of algorithms and their efficiency. An algorithm is simply a sequence of instructions. The efficiency of an algorithm is measured by how much mechanical work it takes to execute all the instructions (time), and/or how much space is used in memory to perform the instructions (space). I'll show how an algorithm can be analysed by working through a famous example.

Analysis Example

Suppose you want to add the numbers 1, 2, ..., 100 together. A simple solution is to iterate over the whole series of numbers, and add them to an accumilating variable, like so: 


    sum = 0
    for i in (1, 2, ..., 100):
        sum = sum + i
Another solution is to notice that 1 + 100 = 101, 2 + 99 = 101, ..., 50 + 51 = 101. With this, we can calculate our answer as follows: 

    sum = 101 * 50
where * means multiplication.

Notice how the first solution requires that we add two numbers together every time the loop iterates. In the end, we will perform addition 100 times. In the second solution, we have to multiply two numbers together. For humans, it might be easier to add two numbers than to multiply two very big numbers together, but because multiplication is such a common mathematical operation, computers have components built into them so that they can perform multiplication just as easily as they could add two numbers together. If it is the case that your computer has such a component, the second algorithm will require a single instruction to be executed once, while the first algorithm will require adition to be executed 100 times.

Generalisation

We can generalise this and ask: What will be more efficient if we had to sum the numbers 1, 2, ..., n together? The first algorithm would look like this: 


    sum = 0
    for i in (1, 2, ..., n):
        sum = sum + i
And the second algorithm would look like this: 

    sum = (n + 1) * (n // 2)
where // means floor division (e.g. 3 // 2 = 1, or 100 // 2 = 50). The first algorithm now requires addition to be performed n times, while alogrithm two requires one addition, one multiplication, and one floor division operation to be performed, regardless of the value of n. As computer scientists, we summarise this by saying that the first algorithm grows by O(n) (it grows linearly as the input grows), while the second grows by O(1) (the amount of computation that has to be done remains constant, regardless of the size of the input). Therefore, the second algorithm will be more efficient thann the first.

Conclusion

Algorithmic analysis is a fundamental discipline within computer science because of the importance of the efficiency of algorithms. It helps us know which algorithms are efficient, and whether they can be used to make solutions to problems tractable.
